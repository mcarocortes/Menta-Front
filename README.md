# Menta (frontend PWA)

Claridad clínica, bienestar consciente.

App React + Vite instalable (PWA): gestión clínica, diario emocional y ejercicios. **Aún no hay API**; los datos de prueba viven en el navegador.

Empieza por el manual, no por adivinar comandos:

**[MANUAL.md](./MANUAL.md)** — guía for dummies: qué instalar, cómo arrancar en Cursor/VS Code, cómo subir a GitHub y cuándo crear el segundo repo (`MENTA_API`).

```powershell
npm install
npm run dev
```
